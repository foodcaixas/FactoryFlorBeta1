# Chão de Fábrica

Jogo 2D de automação industrial (esteiras, máquinas, energia, caminhões e contratos), em uma única página HTML/canvas.

## Como jogar
Abra `index.html` no navegador. O progresso fica salvo no próprio navegador (localStorage).

## Estrutura
- `index.html` — o jogo completo (sprites embutidos)
- `assets/` — sprites originais (máquinas, veículos, terreno)
- `docs/` — notas do projeto, histórico de versões e prompts de sprites
